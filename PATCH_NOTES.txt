Metal Max 4: Gekkou no Diva - English Translation Patch (work in progress)
==========================================================================
Version: 0.9.8 (unofficial fan translation) - 100% of the game's text strings
Game:    Metal Max 4: Gekkou no Diva (Japan), 3DS, Title ID 00040000000AFD00

This is a LayeredFS mod: it does not modify your ROM file. The folder
"00040000000AFD00" contains a replacement "romfs" folder and a "code.ips"
patch for the game's executable.

WHAT'S TRANSLATED
- Every text string in the game: all dialogue, menus, item / weapon /
  armor / tank-part names, monster names, map & location names,
  battle and system messages, skill names, shop names, help texts.
- Item descriptions and skill descriptions (shop, equipment and
  skill screens).
- The in-game Guide: every quest objective and quest description.
- WANTED monster info, bar rumors, Hunter Office special requests,
  quest titles, rental-tank descriptions, encounter-area names.

INSTALL - AZAHAR / CITRA (PC, Android)
1. Right-click the game in the game list > "Open Mods Location"
   (Android: long-press the game > Open Mods Location).
2. Copy the CONTENTS of "00040000000AFD00" (the "romfs" folder and
   "code.ips") into that folder. You should end up with:
      .../load/mods/00040000000AFD00/romfs/...
      .../load/mods/00040000000AFD00/code.ips
3. Start the game.

INSTALL - REAL 3DS WITH LUMA3DS
1. Copy the "00040000000AFD00" folder to your SD card as:
      SD:/luma/titles/00040000000AFD00/romfs/...
      SD:/luma/titles/00040000000AFD00/code.ips
2. Hold SELECT while powering on to open Luma's config and make sure
   "Enable game patching" is checked.
3. Start the game.

IMPORTANT
- Start a NEW GAME, or load a normal in-game save. Do NOT use emulator
  save states made with an older version of the patch: the game caches
  dialogue in memory, and old states show garbled or mismatched text.
- To uninstall, delete the 00040000000AFD00 mod folder.
